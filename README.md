# ECHODEEP

A diving light explores five forgotten caves, mapping the dark with scarce sonar pulses and memory.

Collect every amber echo-shard, then enter the glowing gate. Survive all five depths with three lives. Move with **WASD / arrows**, emit sonar with **Space / click**, pause with **P**, restart with **R**, and start with **Enter / click**. Three pulse charges recharge one at a time; revealed walls fade, so remember the route. Avoid red mines and silt currents.

Run `node serve.ts` and open http://localhost:8080. Build the offline entry with `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to a local output directory). No install or external assets required. All visuals use canvas; sounds use WebAudio synthesis.
